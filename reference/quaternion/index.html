Quaternion Class Reference¶

hammy.Quaternion.Quaternion ¶

Quaternion(value: NDArray | list | tuple | None = None)

Quaternion Class for handling quaternions and their transformations and translations.

Parameters:

Name Type Description Default
value NDArray or list or tuple or None

Quaternion data in scalar-first format [w, x, y, z]. Can be a single quaternion (shape (4,)) or multiple quaternions (shape (N, 4)). If None, creates an empty quaternion object.

 None

Attributes:

Name Type Description
scalar NDArray

The real (scalar) component w of the quaternion(s).
vector NDArray

The imaginary (vector) component [x, y, z] of the quaternion(s).
w NDArray

Alias for scalar component.
x NDArray

x component of the vector part.
y NDArray

y component of the vector part.
z NDArray

z component of the vector part.
num_quaternions int or None

Number of quaternions stored, or None if empty.
conjugate Quaternion

The conjugate quaternion (scalar negated vector part).
magnitude NDArray

Magnitude (norm) of each quaternion.

Examples:

Create a quaternion from a list::

q = Quaternion([1.0, 0.0, 0.0, 0.0])

Create from Euler angles::

q = Quaternion.from_euler([0.0, 0.0, np.pi/2], seq='z', degrees=False)

Get rotation matrix::

rot_mat = q.get_rotation_matrix()

to_euler ¶

to_euler(
    seq: str = "zxz",
    degrees: bool = False,
    intrinsic: bool = True,
) -> NDArray

Calculate Euler rotation angles from the quaternion.

Euler angles refer to sequences of rotations about 2 distinct axes. The supported sequences are: x-y-x, x-z-x, y-x-y, y-z-y, z-y-z, z-x-z.

Intrinsic refers to rotations about the local coordinate system, while extrinsic rotations are about the fixed global axes.

Parameters:

Name Type Description Default
seq str

The Euler angle sequence (one of 'xzx', 'xyx', 'yxy', 'yzy', 'zxz', 'zyz').

 'zxz'
degrees bool

If True, returns angles in degrees; otherwise radians.

 False
intrinsic bool

If True, uses intrinsic rotations; otherwise extrinsic.

 True

Returns:

Type Description
NDArray

Array of shape (N, 3) containing [alpha, beta, gamma] Euler angles.

Raises:

Type Description
ValueError

If seq is not one of the supported sequences.

to_tait_bryan ¶

to_tait_bryan(
    seq: str = "xyz",
    degrees: bool = False,
    intrinsic: bool = True,
) -> NDArray

Calculate Tait-Bryan rotation angles from the quaternion.

Tait-Bryan angles (also called Cardan angles, nautical angles, or yaw-pitch-roll) refer to sequences of rotations about 3 distinct axes. The supported sequences are: x-y-z, y-z-x, z-x-y, x-z-y, z-y-x, y-x-z.

Intrinsic refers to rotations about the local coordinate system, while extrinsic rotations are about the fixed global axes.

Parameters:

Name Type Description Default
seq str

The Tait-Bryan angle sequence (one of 'xyz', 'yzx', 'zxy', 'xzy', 'zyx', 'yxz').

 'xyz'
degrees bool

If True, returns angles in degrees; otherwise radians.

 False
intrinsic bool

If True, uses intrinsic rotations; otherwise extrinsic.

 True

Returns:

Type Description
NDArray

Array of shape (N, 3) containing [alpha, beta, gamma] Tait-Bryan angles.

Raises:

Type Description
ValueError

If seq is not one of the supported sequences.
