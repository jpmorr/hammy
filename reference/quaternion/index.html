    Quaternion Class Reference¶

    Complete API reference for the Quaternion class.

    Class Definition¶

    class Quaternion:
    """Quaternion class for 3D rotation operations."""

    Constructors¶

    __init__¶

    def __init__(self, value: NDArray | list | tuple | None = None) -> None

    Create a quaternion from components.

    Parameters: - value : Array-like of shape (4,) for single quaternion or (N, 4) for multiple. If None, creates empty quaternion.

    Example: 

    q = Quaternion([1.0, 0.0, 0.0, 0.0])
q_batch = Quaternion([[1,0,0,0], [0,1,0,0]])

    from_euler¶

    @classmethod
def from_euler(
    cls, 
    angles: NDArray, 
    seq: str = 'xyz', 
    degrees: bool = False,
    intrinsic: bool = False
) -> Self

    Create quaternion from Euler or Tait-Bryan angles.

    Parameters: - angles : Array of shape (3,) or (N, 3) containing rotation angles - seq : Rotation sequence (e.g., 'xyz', 'zxz', 'zyx') - degrees : If True, angles are in degrees - intrinsic : If True, rotations are about local axes

    Supported Sequences: - Proper Euler: xzx, xyx, yxy, yzy, zxz, zyz - Tait-Bryan: xyz, xzy, yxz, yzx, zxy, zyx

    Example: 

    q = Quaternion.from_euler([30, 45, 60], seq='zyx', degrees=True)

    from_axisangle¶

    @classmethod
def from_axisangle(
    cls, 
    v: NDArray | list | tuple, 
    theta: float | NDArray | list | tuple,
    degrees: bool = False
) -> Self

    Create quaternion from axis-angle representation.

    Parameters: - v : Rotation axis, shape (3,) or (N, 3). Will be normalised internally. - theta : Rotation angle(s), broadcastable with v - degrees : If True, theta is in degrees

    Example: 

    q = Quaternion.from_axisangle([0, 0, 1], np.pi/2)
q_deg = Quaternion.from_axisangle([0, 0, 1], 90, degrees=True)

    from_spherical¶

    @classmethod
def from_spherical(
    cls, 
    theta: float, 
    phi: float, 
    degrees: bool = False
) -> Self

    Create quaternion from spherical coordinates.

    Parameters: - theta : Polar angle (from z-axis) - phi : Azimuthal angle (in x-y plane from x-axis) - degrees : If True, angles are in degrees

    Example: 

    q = Quaternion.from_spherical(np.pi/4, np.pi/3)

    Returns: Arrays of shape (N,) containing respective components.

    conjugate¶

    @property
def conjugate(self) -> Self

    The conjugate quaternion (negated vector part).

    Returns: New Quaternion with [w, -x, -y, -z].

    Example: 

    q = Quaternion([1, 2, 3, 4])
q_conj = q.conjugate  # [1, -2, -3, -4]

    magnitude¶

    @property
def magnitude(self) -> NDArray

    Euclidean norm of the quaternion(s).

    Returns: Array of shape (N,) containing magnitudes.

    num_quaternions¶

    num_quaternions: int | None

    Number of quaternions stored, or None if empty.

    normalise / normalize¶

    def normalise(self) -> Self
def normalize(self) -> Self  # Alias

    Return a unit quaternion.

    Returns: New Quaternion with magnitude 1.

    Example: 

    q = Quaternion([2, 2, 2, 2])
q_unit = q.normalise()  # [0.5, 0.5, 0.5, 0.5]
